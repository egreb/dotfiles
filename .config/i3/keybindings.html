i3 keybindings

$mod = Super (Windows key). Source of truth: ~/.config/i3/config

Launch & window

$mod+EnterOpen terminal (Ghostty)
$mod+dApp launcher (rofi)
$mod+Shift+qClose window
$mod+fFullscreen toggle

Focus

$mod+h/j/k/lFocus left / down / up / right
$mod+←↓↑→Focus (arrow keys)
$mod+aFocus parent container
$mod+Shift+aFocus child container
$mod+spaceToggle focus tiling/floating
$mod+Ctrl+h/lFocus other monitor (left/right)

Move

$mod+Shift+h/j/k/lMove window left/down/up/right
$mod+Shift+←↓↑→Move window (arrow keys)
$mod+Shift+spaceToggle floating
$mod+dragDrag floating window
$mod+Ctrl+Shift+h/lMove window to other monitor (left/right)

Layout & split

$mod+bSplit next window horizontal
$mod+vSplit next window vertical
$mod+sStacking layout
$mod+wTabbed layout
$mod+eToggle split layout
$mod+rResize mode (hjkl/arrows, Esc to exit)

Workspaces

$mod+1…0Switch to workspace 1–10
$mod+Shift+1…0Send window to workspace 1–10
$mod+oBack-and-forth (previous workspace)
$mod+TabNext workspace
$mod+Shift+TabPrevious workspace
1–5 / 6–10Pinned to external (DP-1) / laptop (eDP-1)

Session

$mod+Shift+cReload config
$mod+Shift+rRestart i3 in place
$mod+Shift+xLock screen
$mod+Shift+eExit i3 (with confirm)

Media & screenshot

Vol +/-Raise / lower volume
MuteToggle mute
Mic MuteToggle mic mute
Bright +/-Screen brightness
Play/Next/PrevMedia control (playerctl)
PrintRegion screenshot → clipboard
